# 8Hack

**8Hack is building a place for all hackathons and corporate events.**

8Hack is the ultimate platform for builders, innovators, and creators to discover hackathons, connect with top tech communities, and showcase the projects they've built. We combine the best directory features with premium developer profiles and robust tools for event organizers.

## Features

- **Hackathons**: A comprehensive directory of online, offline, and hybrid hackathons with advanced filtering.
- **Community**: Unified hacker profiles to find your next teammate and connect with developers, designers, and founders.
- **Projects**: A rich gallery showcasing projects built across the world.
- **For Organizers**: Robust tools for hosting hackathons, managing registrations, and automated team formation.
