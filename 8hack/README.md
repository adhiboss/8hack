<p align="center">One-stop platform to find top hackathons from all major platforms curated in a single place for students and hackathon enthusiasts</p>



### Purpose 

I built this platform out of love for Hackathons, because our team had won 3 national-level Hackathons and many batchmates kept asking **"Where do you find these Hackathons?"**

To save time and effort for students, I created this project which **curates top Hackathons from popular platforms like `Unstop`, `Devfolio`, `DoraHacks`**, etc into one place.

### Features

- 🔎 Explore top hackathons from Devfolio, Unstop, DoraHacks, Hack2Skill — all in one place  
- 🗂️ Filter by state or view only online hackathons  
- 💰 Sort by prize, date or recently added  
- 🏫 Submit your college hackathon to get featured  
- 🧰 Tools page to boost your hackathon performance  
- 📱 Install as a PWA for quick mobile access  
- 🎨 Clean bottom nav for mobile-friendly UX
